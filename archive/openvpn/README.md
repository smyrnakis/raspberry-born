# Archived OpenVPN material

> [!CAUTION]
> The files in this directory are retained for historical reference. They contain obsolete, incomplete or unsafe procedures and must not be used as current installation instructions.

Use [the maintained OpenVPN server guide](../../chapters/vpn.md) for a new installation.

## Contents

- `automated/` contains the previous automated guide, the customized third-party installer and its bundled Diffie-Hellman parameters.
- `manual/` contains the older manual guide and its supporting configuration and profile-building files.
- `extras/` contains the former direct-email notification and GPIO LED scripts.

The archive intentionally preserves the old contents without modernizing their commands or internal links. Some links therefore point to paths that have since been replaced.

Do not copy authentication material into this directory. Live `.ovpn` profiles, private keys, TLS keys, passwords, email addresses and public endpoints do not belong in Git.
